# せいざパズル

図形の学習で使う、ピースをはめるパズルのゲームです。こわれた星座のいきものを、ピースでなおしていきます。

- 遊ぶページ：https://rubiziumu37-glitch.github.io/seiza-puzzle/
- 対象：小学校（通常学級・特別支援学級）。タブレットを横向きにして、指で操作します。

## 今の版
- ①土台：登録 → 銀河の地図 → 1-1 うさぎ座 をなおすところまで

## 記録について
- 子どもの記録は、子どもの端末の中（ブラウザの保存領域）にだけ保存されます。このリポジトリやインターネット上には送られません。
- 保存の名前は `seizapuzzle_save_v1` です。この名前と、いきもののID（`usagi` など）は変えないでください。変えると、今までの記録が読めなくなります。
- 遊ぶページのURLが変わると、記録は引き継がれません。

## ファイル
- `index.html`：ゲームの本体（画面・ルール・記録）
- `img/`：絵（ドット絵）。主人公・いきもの・背景
