# せいざパズル

図形の学習で使う、ピースをはめるパズルのゲームです。こわれた星座のいきものを、ピースでなおしていきます。

- 遊ぶページ：https://rubiziumu37-glitch.github.io/seiza-puzzle/
- 対象：小学校（通常学級・特別支援学級）。タブレットを横向きにして、指で操作します。

## 今の版
- ①土台：登録（番号は数字ボタン、名前はランダムか自分で打つ）→ 銀河の地図 → 戦い → なおった！
- ②中核：3つの銀河×（ステージ8＋ボス）＝27体。問題は毎回自動で作る（必ず解ける）。回す・裏返す。ヒント3段階（はまる向き → 置き場所 → 盤の上の影）
- なかま ずかん（★で銅・銀・金のわく、その子が初めてなおした星座の形）、パートナーの とくぎ（演出だけ・9種類）、宇宙服の色（4色）
- 先生のためし用：URLの最後に `#test` をつけると、ぜんぶ開く（保存しない）
- ③画面と出力：先生画面（一覧・カルテ・きろくを あつめる・せっていコード・この たんまつ）、きろくコード（QR＝要約、文字＝くわしい記録）、せっていコード（始める銀河）、効果音、とびきゅう試験

## 先生画面の開き方
- 地図の左上の、名前のところを2秒おしつづける → あいことばを入れる
- あいことばは、元に戻せない形（ハッシュ）でだけコードに入っています。変えたいときは、新しいハッシュに書きかえます

## 外部ライブラリ
- `lib/qrcode.js`（QRを作る）と `lib/jsQR.js`（QRを読む）。ライセンスは `lib/LICENSES.txt`

## 記録について
- 子どもの記録は、子どもの端末の中（ブラウザの保存領域）にだけ保存されます。このリポジトリやインターネット上には送られません。
- 保存の名前は `seizapuzzle_save_v1` です。この名前と、いきもののID（`usagi` など）は変えないでください。変えると、今までの記録が読めなくなります。
- 遊ぶページのURLが変わると、記録は引き継がれません。

## ファイル
- `index.html`：ゲームの本体（画面・ルール・記録）
- `img/`：絵（ドット絵）。主人公（宇宙服の色4種類）・いきもの27体・背景6枚
- `lib/`：QRのライブラリ
